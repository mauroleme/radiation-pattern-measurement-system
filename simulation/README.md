# Simulation

| Folder | Contents |
|---|---|
| [`cst`](cst) | CST Studio Suite projects (Learning Edition): `Yagi868MHz.cst` (the final 6-element Yagi), `Yagi868MHz_tubo_4mm.cst` (variant with 4 mm elements), `Yagi4elem.cst`, `Dipolo868MHz.cst` |
| [`cst/early-versions`](cst/early-versions) | Earlier models: a 433 MHz dipole, `newyagi`, and a first `Yagi868MHz` |
| [`cst/Yagi868MHz_export`](cst/Yagi868MHz_export) | Far-field plots exported from CST at 868 MHz |
| [`nec`](nec) | `Yagi868.nec`: a 4NEC2 model of the same antenna (1 driven, 1 reflector, 3 directors) used for a quick cross-check |
| [`matlab-antenna-toolbox`](matlab-antenna-toolbox) | First Yagi-Uda studies and pattern-search optimisation in MATLAB (March 2025) |
| [`images`](images) | CST model and results, QucsStudio model and results, SimNEC matching, Touchstone validation flow |

Only the `.cst` project files are versioned. The `Result/`, `ModelCache/` and `Temp/` folders (up to 400 MB per project) are regenerated by CST when you open the project and run the solver.

The far-field exports compared against the measurements (`Farfield.txt`, `3dRadiationPattern.txt`) are in [`measurements/2025-05-14_s11-and-farfield`](../measurements/2025-05-14_s11-and-farfield).
